# Valkiria

The `valkiria` MCP server exposes one account owner's ad platforms (Google, Meta, TikTok, LinkedIn, ...),
SMM, SEO/ASO and market analytics.

- Start with `get_started`; it lists the cabinets and scopes this key can see.
- Nothing goes live from these tools. Campaigns are created as drafts, recommendations are proposals;
  the owner approves everything in the Valkiria dashboard (https://valkiria.pro). Say so at the end of each task.
- Reply in the user's language. Keep money in each cabinet's native currency.
- Never invent metrics: `null` means not measured, not zero.
- On `PLAN_LIMIT_REACHED`, point the user to the pricing page in their dashboard.
